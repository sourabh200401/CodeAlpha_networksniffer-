# 🛡️ CodeAlpha - Basic Network Sniffer

## 📌 Project Description

This project was developed as part of the **CodeAlpha Cyber Security Internship Program**.

The Basic Network Sniffer is a Python-based application that uses the built-in **Socket Library** to analyze network communication. It enables users to resolve domain names into IP addresses and understand fundamental networking concepts such as source IP, destination IP, protocols, and network connectivity.

---

## 🚀 Features

* Detects local machine hostname
* Displays local IP address
* Resolves domain names to IP addresses
* Shows source and destination IP information
* Demonstrates TCP/IP networking concepts
* Interactive command-line interface

---

## 🛠️ Technologies Used

* Python 3
* Socket Library
